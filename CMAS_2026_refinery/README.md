# Dataset description — CMAS_2026_refinery
This folder contains the complementary results and datasets used in the work:

*Perspectives on Modeling the Refinery’s Atmospheric Emissions*,
presented at The Air Pollution Conference Brazil, joint with the 6th CMAS South America (2026).

## Data source
- Meteorological data was obtained from [INMET](https://bdmep.inmet.gov.br/), the National Institute of Meteorology, Brazil's official national meteorological service.
- Atmospheric sounding data was obtained from the [University of Wyoming](https://weather.uwyo.edu/upperair/sounding_legacy.html) site.
- Terrain data was obtained from [USSG EarthExplorer](https://earthexplorer.usgs.gov/), a free online search, discovery, and data-download platform created by the U.S. Geological Survey (USGS) EROS (Earth Resources Observation and Science) Center.

The datasets were downloaded from the period corresponing to the data analysis, as the study is set in October 2022.

## Data format
- `.mp4`: videos generated with python showing the dispersion plume of each named pollutant;

## Dataset description
The files correspond to different pollutant dispersion and analysis, (`POLLUTANT.mp4`) as defined and analysed in the article:
- `SO2.mp4`: Sulfur Dioxide (SO<sub>2</sub>).
- `PM25.mp4`: Fine Particulate Matter (PM<sub>2.5</sub>).
- `PM10.mp4`: PM<sub>10</sub>
- `CO2.mp4`: Carbon Dioxide (CO<sub>2</sub>).
- `BC.mp4`: Black Carbon (BC).

## Notes
All datasets are provided in their processed form, as used in the statistical, meteorological and chemical analyses. Detailed information regarding data processing, inclusion criteria, and methodological procedures can be found in the corresponding publication.
