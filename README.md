# ComplementaryData
Repository containing datasets used in published scientific articles &amp; more. 

## About this repository
Created with the purpose of storing and making available the datasets and complenetary results from published scientific articles. The data is provided to promote transparency, reproduibility and data reuse.

## Organization
Each folder corresponds to a scientific publication and contains the data and complementary results from the specific article. Their names are organized as: `EVENT_YEAR_main-key-word`.

## Folders descriptions
- **CMAS_2026_refinery**:
  Contains the datasets associated with the article "*Perspectives on Modeling the Refinery’s Atmospheric Emissions*", presented at The Air Pollution Conference Brazil – Joint with the 6th CMAS South America (2026).

## Notes
All data are provided in their processed form, as used in published analyses. For detailed methodological descriptions, please refer to the corresponding article.
